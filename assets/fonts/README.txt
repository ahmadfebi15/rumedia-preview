FONT TELEGRAF
=============
Website memakai font "Telegraf" (Pangram Pangram, perlu lisensi untuk dipakai di website usaha).
Selama file font belum ada di folder ini, website otomatis memakai Plus Jakarta Sans.

Cara memasang: taruh file font di folder ini dengan nama persis seperti berikut
(cukup salah satu format; .woff2 paling disarankan, .otf/.ttf juga bisa):

  Telegraf-Regular.woff2     (berat 400 - teks biasa)
  Telegraf-Medium.woff2      (berat 500)
  Telegraf-Bold.woff2        (berat 700)
  Telegraf-UltraBold.woff2   (berat 800 - judul)

Opsional: Telegraf-UltraLight, Telegraf-Light, Telegraf-Black.
Setelah file ditaruh, muat ulang website (Ctrl+F5). Tidak perlu mengubah kode.
